# Barony — українська локалізація (uk-UA)

Неофіційний фанатський переклад гри **Barony** (Turning Wheel LLC) українською мовою.

> Проєкт не пов'язаний з розробниками гри. Усі права на гру належать їхнім власникам.

**Чернетка** — переклад є, але не вичитаний (`status=fuzzy`); у мод потрапляє лише з `build.py --drafts`. **Вичитано** — переклад перевірено людиною (`status` порожній), саме він іде в реліз. Ще 1 527 рядків — службові заглушки гри (`DEPRECATED_*`, `null`), не перекладаються.

Версія гри, під яку зроблено переклад: **v5.0.2** (Steam, липень 2026)

## Встановлення

Переклад — це мод, оригінальні файли гри не змінюються.

1. Завантажте архів із [Releases](../../releases) і розпакуйте так, щоб вийшло `<тека гри>\mods\uk-UA\` (типово `C:\Program Files (x86)\Steam\steamapps\common\Barony\mods\uk-UA\`).
2. У грі: головне меню → **Custom Content** → **Local Mods** → `uk-UA` → **Load Mod**.

З репозиторію: `python tools/build.py --install` збирає мод і кладе його в гру, `--uninstall` прибирає; `--drafts` включає й невичитані чернетки (`status` непорожній), інакше беруться лише готові переклади.

## Гілки

- `main` — лише актуальний стан перекладу. Кожен реліз — тег `<версія-гри>-<номер>`.
- Робота ведеться в короткоживучих гілках (`translate/*`, `fix/*`), які зливаються в `main` і видаляються.

Детальніше — у [CONTRIBUTING.md](CONTRIBUTING.md).

## Глосарій

Усталені переклади імен, термінів і назв — у [translation/GLOSSARY.md](translation/GLOSSARY.md). Терміни з глосарію перекладаються тільки так, як там зазначено. Джерело — `translation/glossary.tsv` (з нього ж генеруються глосарій для Weblate і словник для перевірок), `GLOSSARY.md` — згенерований вигляд.

## Структура репозиторію

```
source/                  — оригінальні файли гри (en) за їхніми шляхами в грі; не редагуються вручну
translation/strings.tsv  — усі рядки для перекладу: file, key, original, translation, status, context, entities, tone
translation/files/       — файли, що перекладаються цілком (книги, списки імен), за шляхами в грі
translation/glossary.tsv — глосарій (джерело); GLOSSARY.md — згенерований вигляд для читання
translation/STYLE.md     — правила стилю перекладу
translation/pipeline.toml — технічний опис файлів проєкту (формати, плейсхолдери, групування рядків)
assets/                  — ресурси для гри (шрифти тощо), шлях у репо = шлях у грі
publish/                 — обкладинка мода й описи для Steam Workshop і GitHub Releases
tools/                   — скрипти витягування, збірки та валідації
build/                   — результат збірки (не в git)
```

Тексти гри розкидані по кількох форматах: `lang/en.txt` (рядки `<id> текст#`, коментарі з `#`), десятки JSON у `lang/`, `data/`, `items/` (перекладається лише частина полів) і прості текстові файли (`books/*.txt`). `tools/extract.py` збирає все, що перекладається, в один `translation/strings.tsv`; які саме поля JSON беруться — описано в `tools/barony.py`. Ідентифікатори, плейсхолдери (`%s`, `%d`, `%+d%%`), `$` (місце для значка клавіші), `\n` і службові символи сюжетних текстів (`#`, `^`, `*2`) у перекладі зберігаються як є.

Переклад ставиться в гру як мод (`mods/<назва>/…`): гра накладає файли мода поверх своїх, оригінальні файли не змінюються.

Рядки з непорожнім `status` — чернетки: у мод не потрапляють, доки людина не перегляне їх (у Weblate — «needs editing»). Колонки `context`, `entities` (терміни глосарію, що трапляються в рядку) і `tone` (характер рядка: жарт, погроза, команда…) — довідкові, для перекладача.

Переклад ведеться у Weblate (self-hosted); він працює з PO-файлами в гілці `weblate`, які генеруються з `strings.tsv` і зливаються назад (`tools/weblate.py`). Деталі — у [tools/README.md](tools/README.md).

## Публікація

Steam Workshop: гра заливає мод сама (Custom Content → Upload, тека `mods/uk-UA`); назва, теги й описи (uk/en, BBCode) — у [publish/steam/](publish/steam/), обкладинка `publish/preview.png` потрапляє в мод при збірці. GitHub Releases — архів `build/uk-UA/` у теці `uk-UA/`, нотатки за [publish/github-release.md](publish/github-release.md). Деталі — [publish/README.md](publish/README.md).
